# World English Bible data

These 66 book-level JSON files contain the Protestant canon of the
[World English Bible](https://worldenglish.bible/), a public-domain
translation.

The files were generated from `eng-web.usfx.xml` in
[`seven1m/open-bibles`](https://github.com/seven1m/open-bibles) at revision
`f257a3559025c3f873b48a75019f53a9354ed7de` using
`scripts/generate-web-data.py`.

Verse markers and study notes are omitted from the generated reader text.
The complete verse text is retained and grouped into paragraphs by chapter.
